# Getting started with Groundwork

This takes about 15 minutes, and you only do it once. You don't need to install anything yourself first.

## Before you start

- Use a Windows laptop.
- **Connect to the internet.** The first start downloads about 150 MB. On slow Wi-Fi, that can take a while.
- After this first time, Groundwork works **without internet**.

## 1. Download it

1. Open **https://github.com/noachFrank/groundwork** in your web browser.
2. Click the green **Code** button.
3. Click **Download ZIP**.

## 2. Unzip it

1. Open your **Downloads** folder.
2. **Right-click** the file called **groundwork-main.zip**.
3. Click **Extract All…**.
4. Where it asks for a location, delete what's there and type **`C:\Groundwork`**.
5. Click **Extract**.

> Don't skip this step. Double-clicking files while they're still inside the zip won't work.
> Don't put it in OneDrive, Documents or Desktop. `C:\Groundwork` is best.

## 3. Start it

1. Open **`C:\Groundwork`**, then open the **groundwork-main** folder inside it.
2. Double-click **start.bat**.
   - If a blue box says **"Windows protected your PC"**, click **More info**, then **Run anyway**. That appears for any new file from the internet.
3. A black window opens and starts downloading. **Leave it open and wait.** It shows each step as it goes.
4. When it's done, Groundwork opens in your web browser by itself.

If it stops with a message about the internet, reconnect and double-click **start.bat** again. It carries on from where it stopped.

## Every day after that

- **To start:** double-click the **Groundwork** shortcut on your Desktop. No internet needed.
- **While you study:** keep the black window open. You can minimize it.
- **When you're done:** close the black window.

## Good to know

- **No internet?** Lessons, quizzes, coding exercises and labs all still work. Anything that needs internet, like a video, says so clearly. Connect later to do those bits.
- **New lessons:** when you're told new lessons are ready, close Groundwork, connect to the internet, and double-click **update.bat** in the same folder. Your progress is kept.
- **Back up your progress:** in the app, go to **Settings**, then click **Download a backup**. Keep the file somewhere safe, like a USB stick or your email.
- **Something unclear in a lesson?** Click **Something unclear or wrong?** on that lesson, any time. At the end of each lesson there's also a short **How clear was this?** box. Fill them in honestly, especially when a lesson used a word it never explained.
- **Once a week, send your feedback.** Go to **Settings**, then **Send feedback**, and click **Download feedback file**. Send that file to whoever gave you Groundwork (on WhatsApp, attach it as a document). Each file only contains what's new since your last one. Sent something too early? Click **Mark as not sent** on it, change it, and it goes out next time. The **Today** page reminds you when a week has passed.

## If something goes wrong

| What you see | What to do |
| --- | --- |
| "This file needs to be run from an extracted folder" | Do step 2 (Unzip it) again |
| "Groundwork can't run from a OneDrive folder" | Move the folder to `C:\Groundwork` |
| "Could not download…" | Check your internet connection, then double-click start.bat again |
| The browser says "This site can't be reached" | Make sure the black window is still open. If not, start Groundwork again |
| Something else | Take a photo of the black window and send it to whoever gave you Groundwork |
