## A very polite text conversation

**HTTP** is the language browsers and servers use. Here's a real request. It really is just text:

```
GET /orders/102 HTTP/1.1
Host: localhost:4314
Accept: application/json
```

- `GET` is the **method**: what you want to do.
- `/orders/102` is the **path**: what you want to do it to.
- The lines after it are **headers**: extra information about the request.

And the response:

```
HTTP/1.1 200 OK
Content-Type: application/json

{ "id": 102, "customer": "Grace", "item": "Monitor" }
```

- `200 OK` is the **status**: how it went.
- Then come headers, a blank line, and the **body**: the actual content.

## Methods: what do you want to do?

| Method | Meaning | Example |
| --- | --- | --- |
| GET | Read something | See order 102 |
| POST | Create something | Place a new order |
| PUT | Replace or update | Change an order |
| DELETE | Remove | Cancel an order |

## Status codes: how did it go?

The first digit tells you who to look at:

| Family | Meaning | Common examples |
| --- | --- | --- |
| **2xx** | It worked | `200 OK`, `201 Created` |
| **3xx** | Go elsewhere | `301 Moved Permanently`, `302 Found` |
| **4xx** | Your request has a problem | `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`, `429 Too Many Requests` |
| **5xx** | The server has a problem | `500 Internal Server Error`, `502 Bad Gateway`, `503 Service Unavailable` |

<Callout title="Stateless">
HTTP has no memory: each request stands alone, and the server doesn't recall the last one. So how do websites keep you logged in? **Cookies**. The server gives your browser a small piece of text, and the browser sends it back with every request after that.
</Callout>

<ConsultantNote>
A status code cuts through a confusing bug report fast. "The app is broken" could be a 401 (their login expired), a 404 (a wrong link), or a 503 (the server's down), and each one is a completely different problem. Opening the browser's Network tab (F12) and reading the status code is often step one of a diagnosis.
</ConsultantNote>
