## IP addresses find computers

An **IP address** identifies a computer on a network. Most look like four numbers with dots: `142.250.190.78`. That format is **IPv4**. There's a newer, longer format called **IPv6**, like `2607:f8b0:4009::200e`. They do the same job.

A few are worth recognizing:

| Address | What it means |
| --- | --- |
| `127.0.0.1` | This computer. Also known as `localhost`. |
| `192.168.x.x` or `10.x.x.x` | Private. Only meaningful inside a home or office network. |
| Anything else, generally | Public: reachable from across the internet. |

Your laptop probably has a private address like `192.168.1.23`. Your router shares one public address for everyone at home. That's why a server on your laptop can't normally be reached from outside.

## Ports find programs

A computer runs many programs that use the network at once. Each server program **listens** on a numbered **port**, from 1 to 65535.

Think of an apartment building: the IP address gets a letter to the building, and the port is the apartment number.

| Port | Usually |
| --- | --- |
| 80 | HTTP (unencrypted web) |
| 443 | HTTPS (encrypted web) |
| 22 | SSH (logging in to a server remotely) |
| 5432 | PostgreSQL, a database |

So `https://example.com` really means `https://example.com:443`. The browser fills in the port when it's the standard one. Developers constantly run things on other ports, like `http://localhost:3000`.

If nothing is listening on a port, the connection is **refused**. You'll see that for yourself in the task.

## TCP and UDP: two ways to send

Messages travel in small chunks called **packets**. Two protocols handle most of them:

- **TCP** is like a phone call. It sets up a connection, confirms everything arrives, re-sends what's lost, and keeps it all in order. The web, email and file transfers use it.
- **UDP** is like posting postcards. It just sends. It's faster, with no guarantee. Video calls and DNS lookups use it.

<ConsultantNote>
"Connection refused" and "connection timed out" are clues. **Refused** means the computer answered but nothing is listening on that port, so the service is probably down. **Timed out** means nothing answered at all, so suspect a firewall or the wrong address.
</ConsultantNote>
