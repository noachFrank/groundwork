## Names for people, numbers for computers

Nobody wants to remember `142.250.190.78`. **DNS**, the Domain Name System, is the worldwide directory that turns names into addresses.

No single computer holds the whole thing. It's split among many servers, arranged in a hierarchy. Here's a full lookup:

<Viz name="dns-lookup" />

## The cast

- **Resolver:** does the legwork for you. It's usually run by your internet provider, or a public service like `1.1.1.1`.
- **Root servers:** the top of the tree. They don't know addresses, just who handles `.com`, `.org`, and so on.
- **Top-level domain (TLD) servers:** know who handles each domain under `.com`.
- **Authoritative server:** the source of truth for one domain. When you "edit DNS" in a domain's control panel, this is what you're changing.

## The records you'll actually use

| Type | What it does | Example |
| --- | --- | --- |
| A | Name to IPv4 address | `shop.example` → `93.184.216.34` |
| AAAA | Name to IPv6 address | `shop.example` → `2606:2800::1` |
| CNAME | Name to another name | `www.shop.example` → `shop.example` |
| MX | Where email goes | `shop.example` → `mail.provider.example` |
| TXT | Free text, often for proving you own a domain | `v=spf1 include:...` |

## Caching, and why changes aren't instant

Going through all those servers on every lookup would be slow. So every answer comes with a **TTL** (time to live): how many seconds it may be saved. Your laptop and your resolver both keep copies.

That's what the opening question was about. After you change a record, anyone holding a saved copy keeps the old answer until it expires. Different people's copies expire at different times, so a change seems to spread gradually.

<Callout title="A useful trick">
Moving a site next week? Lower the TTL now, for example to 300 seconds. Once the old, longer TTL has passed, everyone's copies expire quickly, so the actual move takes effect within minutes. Raise it again afterward.
</Callout>

<ConsultantNote>
"It's always DNS" is a running joke in IT because so many outages trace back to it. A site suddenly unreachable, email going missing after a host change, a domain that expired because nobody renewed it: all DNS. Asking "who controls your DNS, and when does the domain renew?" is a great early question with a new client.
</ConsultantNote>
