## A command is a sentence

Almost every command has the same shape:

```text
Copy-Item   notes.txt backup.txt   -Force
└ command   └ arguments            └ option (flag)
```

- The **command** is the verb: what to do.
- **Arguments** are what to do it to.
- **Options**, also called flags or parameters, start with a dash and change how it's done.

PowerShell names its commands **verb-noun**: `Get-ChildItem`, `Copy-Item`, `Remove-Item`, `Get-Process`. Once you know that, you can often guess a command's name. Many also have short names borrowed from older systems, like `ls`, `cd`, `cat` and `pwd`.

## The shortcuts that matter

| Key | What it does |
| --- | --- |
| **Tab** | Finishes a command or file name. Press it again to cycle through matches. |
| **Up arrow** | Brings back your previous commands. |
| **Ctrl+C** | Stops whatever is running. |
| **cls** | Clears the screen. Nothing is deleted. |
| **Right-click** | Pastes, in PowerShell's window. |

Tab completion also prevents typos. If Tab doesn't complete a file name, the file probably isn't where you think.

## Connecting commands

Two symbols turn small commands into powerful ones:

- `|`, the **pipe**, sends one command's output into another. `Get-Process | Sort-Object CPU` lists programs, then sorts them.
- `>`, **redirect**, sends output into a file instead of the screen.

## Reading errors

Red text isn't the computer shouting at you. It's a message, and usually a precise one:

```text
Get-Content : Cannot find path 'C:\...\does-not-exist.txt' because it does not exist.
```

That says which command failed (`Get-Content`), what went wrong (it can't find the path), and the exact path it tried. Most of the time the fix is in the message.

## Which shell is which?

A **shell** is the program that reads your commands. You'll meet three:

| Shell | Where |
| --- | --- |
| **PowerShell** | Modern Windows. What we use in this course. |
| **Command Prompt** (cmd) | Older Windows. Still used by `.bat` files. |
| **Bash** | Linux servers and Mac. Most servers on the internet run Linux, so you'll meet it next. |

The ideas are the same everywhere. Only the command names differ.
