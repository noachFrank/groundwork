## Modern JavaScript reads like a pipeline

You could write every JavaScript loop the Python way, with `for`. But real-world JavaScript, including most AI-written code, uses **array methods** chained together:

```javascript
const londonNames = orders
  .filter((o) => o.city === "London")
  .map((o) => o.customer);
```

Read it top to bottom, like a recipe: **take the orders → keep the London ones → turn each into a name.**

## Arrow functions

`(o) => o.city === "London"` is an **arrow function**: a small function with no name, written inline. These all mean the same thing:

```javascript
function isBig(o) { return o.total > 100; }
const isBig = (o) => { return o.total > 100; };
const isBig = (o) => o.total > 100;      // one expression is returned automatically
```

## The four methods you'll see most

| Method | Does | Example | Gives |
| --- | --- | --- | --- |
| `filter` | Keeps items where the function is true | `[1, 2, 3, 4].filter(n => n > 2)` | `[3, 4]` |
| `map` | Turns each item into something else | `[1, 2, 3].map(n => n * 10)` | `[10, 20, 30]` |
| `find` | Gets the first match | `[1, 2, 3].find(n => n > 1)` | `2`, or `undefined` if none |
| `reduce` | Combines everything into one value | `[1, 2, 3].reduce((sum, n) => sum + n, 0)` | `6` |

## Objects

JavaScript **objects** are like Python dictionaries, but you usually read them with a dot:

```javascript
const order = { id: 101, customer: "Ada", total: 49 };
order.customer          // "Ada"
order["customer"]       // also "Ada"
order.phone             // undefined, with no error yet
order.phone.length      // TypeError: Cannot read properties of undefined
```

## undefined, and how to cope with it

JavaScript gives `undefined` for things that don't exist: a missing property, a `find` with no match. It doesn't complain, until you try to use it. "**Cannot read properties of undefined**" is probably the most common JavaScript error in the world.

Two modern helpers:

- `order.customer?.name` reads `name` only if `customer` exists. Otherwise it gives undefined, with no crash.
- `value ?? "default"` uses the default when the value is null or undefined.

<ConsultantNote>
When you read a client's frontend code, these chains are everywhere, often several lines long. Reading them step by step, saying "keep the ones that…, turn each into…", is the skill. When they're too long to follow, that's worth mentioning in a review, too.
</ConsultantNote>
