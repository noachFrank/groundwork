## Small scripts, big savings

You now know enough Python to write genuinely useful programs. The most valuable ones are often tiny: 20 to 50 lines that remove a boring manual job someone does every week.

Good candidates are tasks that are **repetitive**, **follow rules**, and happen **on a computer**: combining spreadsheets, renaming files, checking data, producing reports.

## The shape of most scripts

Almost every small script follows the same three steps:

```text
read the data  →  work something out  →  write the result
```

| Step | Common tools |
| --- | --- |
| **Read** | `open()` for text files, `csv` for spreadsheet exports, `json` for API data |
| **Work it out** | loops, `if`, dictionaries for grouping, `sum`, `sorted` |
| **Write** | `open(..., "w")`, `print()`, or send it to an API |

## CSV files

Spreadsheets export as **CSV**: plain text with one row per line and commas between values. The first line is the column names.

```text
date,category,amount
2026-03-01,Travel,42.50
```

Python's `csv.DictReader` gives you each row as a dictionary: `{"date": "2026-03-01", "category": "Travel", "amount": "42.50"}`. Notice the amount is **text**. Convert it with `float()` before doing maths with it.

## Grouping with a dictionary

Totals per category, per customer or per month all use the same pattern, a running total with one entry per group:

```python
totals = {}
for row in rows:
    key = row["category"]
    if key not in totals:
        totals[key] = 0
    totals[key] = totals[key] + float(row["amount"])
```

## Writing files

```python
with open("report.txt", "w") as f:
    f.write("Travel: 94.50\n")
```

`"w"` creates or **replaces** the file. `"a"` adds to the end. `with` closes the file for you when the block ends. `\n` starts a new line.

<Callout kind="warn" title="Scripts repeat mistakes perfectly">
A bug in a script that edits data gets applied to every row, instantly. Always run new scripts on a **copy** of the data first, and keep a backup of the original.
</Callout>

<ConsultantNote>
A script that saves a client's office manager two hours a month is often worth more to them than a big new system. Look for these during discovery: ask "what do you do every week that feels like copying and pasting?" The answers are often quick, cheap wins that build trust.
</ConsultantNote>
